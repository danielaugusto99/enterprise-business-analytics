# 📊 Enterprise Business Analytics Dashboard

Painel analítico interativo de alta performance desenvolvido em Python para monitoramento de KPIs estratégicos, análise de vendas por região/categoria e rastreamento de lucratividade temporal.

---

## 🛠️ Tecnologias Utilizadas
* **Python 3.10+**
* **Streamlit** (Framework para aplicações web interativas)
* **Pandas & NumPy** (Manipulação e engenharia de dados)
* **Plotly** (Visualização de dados avançada e responsiva)
